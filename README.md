# ShareAmigo

An app created for South African university students for the purpose of Sharing and trading, clothing, tech and stationery with other students on campus.

# About

Student life is expensive and daunting. Many students have things they do not need. Others need those same things.
ShareAmigo connects them. Students can give, request and exchange items with people on their own campus.

# Features

- Sign up and log in
- OTP function 
- Post items to share (food, clothing, stationery, used tech)
- Browse and search available items
- Request an item from another student
- Edit or delete your own listings
- Messeging between students
- Manage your profile
